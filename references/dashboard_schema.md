# Dashboard Payload and Component Schema (`dashboard.html`)

The standalone HTML5 dashboard generated by `scripts/generate_dashboard.py` embeds a structured JSON state payload (`window.JASPAR_DASHBOARD_STATE`) that drives client-side rendering, theme resolution, and interactive recalculations without external network dependencies.

## 2. Dashboard UI Panes and Interactive Controls
1. **Top Navigation Bar**: Displays TF symbol, Matrix ID, version token, species taxonomy (`Homo sapiens [TaxID: 9606]`), TFClass pathway, runtime/SSE status indicator (`#sseStatusBadge`), and the three-icon segmented theme selector (`#theme-btn-light`, `#theme-btn-dark`, `#theme-btn-system`).
2. **Input Data & Live Sequence Scanner**:
   - Displays processed sequence metrics (length in bp, observed GC%, A/C/G/T base counts, and total binding sites).
   - Provides a JASPAR profile switcher, relative cutoff slider, sequence preset buttons, motif site injector, editable sequence textarea (`#liveSequenceInput`), and live **Run Sequence Scan** button (`#btnRunScan`).
3. **Information-Theoretic Sequence Logo Pane**:
   - Interactive toggle buttons for **Forward (5' -> 3')** vs. **Reverse Complement (3' <- 5')** and **Information Content (Bits)** vs. **Position Probability (0-1)**.
   - **Download SVG** export and bottom **IUPAC Consensus Sequence Strip**.
4. **3D Interactive SVG Viewport (`#viewport3DSurface`)**:
   - Toggles between the **Interactive Relationship Node Map** (3D force-directed node-link topology) and **Structural Data Diagram** (3D B-DNA double-helix representation) with mouse drag rotation, Shift+drag pan, scroll zoom, and node inspection.
5. **Position Frequency, Probability & Log2-Odds Weight Matrix (PFM / PPM / PWM Explorer)**:
   - Mode selector (`PWM Log2-Odds`, `PPM Probabilities`, `PFM Raw Counts`) with smooth semantic heatmap gradient interpolation (`Surface -> #0D9488 -> #4F46E5 -> #E11D48`).
   - Live interactive sliders for **Pseudocount (`0.1` to `5.0`)** and **Background GC Content (`0.20` to `0.80`)** that recalculate PPM/PWM cells in real time.
   - Format export buttons (`JASPAR`, `MEME`, `TRANSFAC`, `YAML`) with copy-to-clipboard support.
6. **TFClass Structural Domain Classification & Familial Cluster Comparison**:
   - Displays the TFClass hierarchy pathway (`Superclass -> Class -> Family -> Subfamily`), direct UniProt/PDB links, and comparison metrics (Pearson $r$ and mean Jensen-Shannon divergence) across canonical, BPNet, and paralog profiles.
7. **Genomic Coordinate Binding Locus Map & Hit Table**:
   - SVG genomic coordinate track showing forward (`+`) and reverse (`-`) strand binding hits along the scanned sequence, plus a searchable, filterable hit table.
8. **Workspace Provenance, Validation Telemetry & Academic Citations Footer**:
   - Displays the JASPAR 2026 and JASPAR 2024 Nucleic Acids Research citations, CC BY 4.0 license link, empirical execution telemetry table, and experimental validation notice.
